# 🐍 Automation & Web Scraping - Annuaire OEC Maroc

## 📌 Présentation
Script d'extraction automatisée développé en Python pour collecter et structurer les données publiques de l'Ordre des Experts-Comptables du Maroc.

## 🛠️ Technologies & Librairies
- **Python 3.x**
- **Playwright / BeautifulSoup** (Extraction dynamique)
- **Pandas** (Nettoyage et structuration des données)

## 🎯 Objectif Business
Convertir des données web non structurées en un jeu de données propre (CSV/Excel) pour l'analyse sectorielle, la cartographie des cabinets et l'intelligence économique.# Python-Web-Scraping-OEC
